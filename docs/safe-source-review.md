## What was created

src/data/work-samples.json contains only manually composed, anonymized process summaries. The homepage presents these as expandable work samples, explicitly labelled recreated summaries. writeups/landsafe-due-diligence.md and writeups/mlc-nomination.md preserve the case narratives for future case pages. Portfolio JSON points to these existing writeups.

The original report, dossier, SOPs, charts, scans, and extracted source text are not public assets or downloads. Rendered source pages and raw text were used only in an external temporary review folder. No original-source URLs or local client paths are placed in the UI, JSON, or case writeups. No external service was used to upload or analyze these files.

## Withheld information

- Personal/client names, family relationships, photographs, identifying biographical details, addresses, telephone numbers, email addresses, signatures, and identity documents.
- Parcel locations, maps, coordinates, survey numbers, registration references, areas, dimensions, boundaries, QR codes, and access descriptions specific to a property.
- Property valuations, transaction prices, mortgage details, report scores, dispute findings, recommendations, and dated transaction timelines.
- Internal campaign structure, personnel assignments, voter/booth lists, community-level targeting, and private operational or strategy material.
- Individual-case outcomes, investment forecasts, and nomination approval claims.

Existing aggregate résumé metrics remain separate from the client work sample. The supplied material supports deliverable and method descriptions; it does not independently substantiate those aggregate metrics.
