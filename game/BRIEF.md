# Interactive portfolio brief

Goal: let a recruiter inspect how Harith coordinated work and organized evidence, while reaching project content directly.

Map: existing homepage → Products (TidyRow and ColdConnect) → Vivek plant workstreams → LandSafe report workflow → political research and nomination-document preparation → About → Contact.

Mechanic: select a workstream or workflow stage and inspect the matching spatial state. This adapts the control-room option for Founder’s Office roles to the approved cinematic homepage. A fly-between city was considered but would replace the existing page flow, contrary to the approved design. No separate game route or mandatory game intro is added.

Controls: click/tap or keyboard buttons. Desktop plant responds to section scroll; phone uses a labelled layer slider. LandSafe and research use direct stage buttons. Scene state and explanation share the same selected value.

Stops: the existing hero projects tidyrow and coldconnect remain directly visible in Selected Work. Supporting experience stays in its existing sequence rather than becoming additional hero-game stops. Their existing problem, contribution, metrics where supplied, and proof remain content, not rewards locked behind interaction. Home and contact remain normal anchor destinations.

Skip: the existing skip-to-content and Work navigation remain; each new experience chapter has a visible Read the work link to its plain HTML case strip. No visitor must interact with WebGL to read the work.

Look: approved amber/cream/forest portfolio, warm studio lighting, matte terrain and paper, silver plant equipment, brass details. No external source assets copied; all new scene geometry is authored locally. Source documents inform anonymized summaries, not texture images.

Done when: all existing hero projects remain directly reachable; controls work at 375px and via keyboard; meaningful content appears without waiting for scenes; reduced-motion and WebGL-fallback paths retain content; no new outcome or sensitive detail is invented. Local timing observations are not a universal under-three-second network-load guarantee.

Implementation adapts folio-game's control and content principles to the already approved cinematic design. It does not claim completion of a standalone playable-world workflow or external-link confirmation by the user.
